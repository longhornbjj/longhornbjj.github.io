Hello to any future UTBJJ officers who may edit this!

Some things to note:

- This website was made using the Bootstrap framework. It makes website building much easier due to the grid layout system. 
    If you're familiar with basic web dev languages like HTML, CSS, and JS, then I would definitely recommend looking into the docs
    and finding tutorials online. Unless of course you're a CS major and much smarter than myself.

    Bootstrap docs: https://getbootstrap.com/docs/5.3/getting-started/introduction/

- You can totally ignore the above statement if you just want to edit some text or do something simple rather than edit the website
    layout. To do that you would replace the (usually) WHITE text in the HTML document. Text displayed on the website is found in a variety of HTML "tags":

    <p>Hello</p> = "Paragraph"
    <h1>Hello</h1> = "Heading" (1-5 with 1 being the biggest)

    Bootstrap lets you apply "Classes" to div sections that affects the font size of the text, making it act an h1-h5, p, or whatever else you may want.

    To replace images, you would find an image tag, replace the src="" with a link to your image, and replace the alt="" with a short descrition of the image in case it fails to load for the user.

    Example image tag: <img src="bjj.png" alt="two members rolling">

    To replace a link, you would do something similar but with the "a" tag. In this case you would fill in href="" with whatever link you want.

    Example "a" tag: <a href="samplelnk.com">Sample text</a>
